# Заметки по форку (что отличается от s-kella/french-trainer)

Код: один файл `index.html`. Слова и прогресс лежат не в git, а в базе артефакта (документ `data/users/<id>/state`). Эти заметки нужны, чтобы потом перенести приложение на свой хостинг.

## Типы заданий
- `word` — русское слово → слово на языке колоды. Боксы 1–2: выбор из 4 похожих, 3+: ввод.
- `cloze` — фраза с пропуском `___`: `[фраза, ответ, [3 ловушки], перевод]`.
- `number` — цифра → слово (стандартный и швейцарский вариант).
- `conjug` — глагол и его формы: `[инфинитив, [формы…], перевод, (подсказки)]`. Шаг 1 (боксы 1–4): найти глагол по русскому. Шаг 2: формы. Боксы 1–2 — выбор из 4 похожих форм других глаголов (режим сопоставления выключен, включается `deck.matching=true`). Бокс 5: только русский перевод и ввод.
- `verb` — инфинитив ↔ причастие (из оригинала).

## Свойства колоды (в документе колоды)
`lang` (code, name, accentChars, looseStress, articlePattern), `pronouns` (с `variants` и `elideLabel`/`elideSay`), `conjugPrompt`, `explain` (пояснения по ключу «первое поле строчными»), `explainDefault`, `startDueOffsetDays`, `matching`, `shared`.

## Что добавлено
- Греческий: ударение, роды прилагательных, подсказки по буквам, точка в конце не ошибка.
- Явная обратная связь, переводы у вариантов выбора (после неверного — у нажатого, после верного — у всех), пояснения после слова, откат результата (повтор без зачёта), баннер при сбое сохранения.
- Из оригинала перенесены: падение выученного слова в бокс 4 после ошибки, Enter на итоговом экране, счётчик ошибок при разборе, оформление итога.

## Общий доступ (для маминого аккаунта)
- `decks/<id>` — общие копии греческих колод (lang `el*` или `shared:true`). Страница владельца сама пишет их при изменениях; у остальных страница подмешивает их в личное состояние при загрузке.
- `summaries/<id>` — сводка (боксы, выучено, активность, здоровье). `copies/<id>` — копия прогресса по словам. Читает только владелец; пишет сам человек.
- Права (rules): `decks` read view / write owner; `summaries`, `copies` read/write owner; `summaries/{self}`, `copies/{self}` interact.
- Экран «Участники» (только владелец): таблица с именем, почтой, боксами, проблемами и раскрывающимся прогрессом по словам. Нужны scopes `profile`, `email` у capability `user`.
- Важно: `user.isOwner()` возвращает Promise, его нужно ждать.

## Что держится на платформе Claude (для переноса на свой хостинг)
- `claude.use("db")`: `doc(path).get/set/update`, `collection(path).get`.
- `claude.use("user")`: `id()`, `isOwner()`, `profiles(ids)` (имя, почта).
- Права на пути (кто что читает/пишет) задаются платформой — на своём хостинге это должны делать правила базы.
- Запасной режим без платформы: `localStorage` (прогресс только в этом браузере).
