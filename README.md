# Emlék — тренажёр французских слов

Флешкарточки с интервальным повторением (Leitner: 5 боксов, чем выше
бокс — тем реже слово повторяется). Код и данные — на платформе
Claude (Artifact), не на обычном сервере. Прогресс и колоды каждого
пользователя лежат в `data/users/me/state`.

## Установка (один раз)

Сделать это руками нельзя — Artifact на claude.ai публикуется только
через Клода (это его внутренний инструмент, у пользователя нет формы
«вставь HTML и получи ссылку»). Поэтому первый шаг обязательно
делает Клод, по твоей просьбе в чате.

1. Открой чат с Клодом (claude.ai или Claude Code).
2. Попроси его опубликовать `index.html` из репозитория
   https://github.com/s-kella/french-trainer как новый Artifact со
   своей собственной ссылкой и нужными capabilities для хранения
   прогресса.
3. Клод опубликует страницу и даст тебе ссылку на неё — это и есть
   твой тренажёр. Сохрани эту ссылку, дальше заходишь по ней.

Если у Клода нет доступа в интернет (например, в Claude Code без
веб-поиска) — склонируй репозиторий сам (`git clone
https://github.com/s-kella/french-trainer`) и попроси Клода
опубликовать Artifact из локального файла `index.html`.

Когда в репозитории появятся обновления — попроси Клода взять
свежий `index.html` (заново открыть репозиторий или `git pull`,
если клонировал) и republish-нуть его на ту же свою ссылку (в
запросе на Artifact указать уже существующий `url`, чтобы не
создалась новая страница и не потерялись твои данные).

## Виды тренировок (deck `kind`)

1. **verb** — глагол: инфинитив → participe passé, подсказка — перевод.
2. **word** — слово ⇄ перевод, направление каждый раз случайное.
3. **cloze** — фраза с пропуском `___` (предлоги/артикли): 1 правильный
   ответ + 3 варианта-ловушки.
4. **conjug** — спряжение глагола в présent, все 6 форм одной
   карточкой. На низких боксах — сопоставление (тапнуть местоимение →
   тапнуть форму), на высоких — ввод всех 6 форм. Засчитывается
   "чисто", только если верны все 6 форм.

Новые наборы слов не появляются автоматически — после того как
подтянешь обновлённый `main` и republish-нешь свою копию, новый набор
станет виден на экране **«Доступные наборы»** (иконка рядом с
«Наборы слов»), с чекбоксом. Добавляешь его себе сам, по желанию —
после этого это уже твоя независимая копия, можешь свободно
дописывать туда свои слова.

## Как добавлять/менять слова и наборы вручную (через интерфейс)

1. Открой значок ⚙️ «Наборы слов» в правом верхнем углу.
2. В выпадающем списке выбери существующий набор — или «+ Новый
   набор», впиши название, выбери тип (глаголы / просто перевод /
   вставить пропуск / спряжение) и нажми «Создать набор».
3. В текстовом поле — по одной строке на слово, поля через `;`.
   Формат зависит от типа набора (подсказка над полем подскажет
   точный формат для выбранного набора):
   - глаголы: `infinitif;participe passé;перевод`
   - просто перевод: `слово;перевод`
   - вставить пропуск: `фраза с ___;ответ;ловушка1|ловушка2|ловушка3;перевод`
   - спряжение: `infinitif;je|tu|il|nous|vous|ils;перевод` (можно
     добавить четвёртое поле `я…|ты…|он…|мы…|вы…|они…` — перевод по
     лицам, необязательно)
4. Нажми «Сохранить» — карточки пересоберутся, прогресс по уже
   существующим словам не пропадёт.
5. «Сбросить прогресс (этот набор)» и «Удалить этот набор» — там же,
   под текстовым полем.

Если редактируешь существующий набор, его текущие слова уже будут в
этом поле в том же формате — можно просто дописать новые строки и
сохранить.

## Как добавлять/менять слова и наборы через Клода

Если это делает Клод через Artifact-инструмент: `read_db` (collection
`data/users/me`, doc_id `state`) → внести изменения в полученный
JSON → `write_db` (`set`) тем же collection/doc_id целиком обратно.
Не трогай кусок документа вслепую — всегда читай весь объект, меняй
его в памяти, пиши весь объект обратно, чтобы не потерять остальные
колоды/прогресс.

Формат одного слова (массив, не строка с `;` — так нужно для
raw-данных; `;` используется только при ручном вводе через интерфейс):

- `verb`: `[infinitif, participe_passé, перевод]`
- `word`: `[слово, перевод]`
- `cloze`: `[фраза с ___, ответ, [ловушка1, ловушка2, ловушка3], перевод]`
- `conjug`: `[infinitif, [je, tu, elle, nous, vous, elles], перевод]`

В том же JSON-документе `state` у корня два поля: `decks` (сами
наборы и слова) и `progress` (прогресс по каждому слову). Новая
колода = новый ключ внутри `decks`:

```json
{
  "decks": {
    "<deckId>": {"kind": "...", "name": "...", "words": [...]}
  }
}
```

Для каждого добавленного слова нужен ещё и прогресс — отдельный
новый ключ внутри `progress` (не внутри `decks`!), на одном уровне с
другими словами всех наборов. Ключ составляется так:
`<deckId>::<wordKey>`, где `deckId` — ключ колоды из `decks` выше, а
`wordKey` — первое поле слова (например, для `word` это само слово),
в нижнем регистре, без пробелов по краям. Значение — объект вида:

```json
{
  "progress": {
    "<deckId>::<wordKey>": {"box": 1, "due": "<сегодняшняя дата, ГГГГ-ММ-ДД>", "learned": false}
  }
}
```

Пример: добавили в колоду `deck-abc123` слово `["chat", "кот"]` —
значит нужен и `decks["deck-abc123"].words` с этим словом, и
`progress["deck-abc123::chat"]` с объектом прогресса выше.
